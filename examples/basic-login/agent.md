# Login Test Context

This is a simple login test for demonstration purposes.

## Application Behavior
- Login form appears immediately after page load
- Successful login redirects to dashboard
- Dashboard contains a welcome message

## Test Credentials
- Email and password are provided in the test steps
- No special authentication flow (standard form submission)

## Timing
- Page loads are typically fast (<2 seconds)
- Login response is immediate
- Dashboard appears without delay

## UI Elements
- Email input has label "Email"
- Password input has label "Password"
- Submit button is labeled "Sign In" or "Login"
- Success indicator is the welcome message on dashboard
